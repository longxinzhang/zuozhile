# 算法审查与优化次序

日期：2026-09-23。范围为当前规则实现、数据流和可执行复现，不是医学有效性或人群准确率研究。
本次只实现嘴部新输入与评分；以下坐姿、抬头、提醒和统计问题尚未修改。

## 总体判断

“本地关键点 + 个人基线 + 相对偏移 + 持续时间/冷却”的框架适合做低打扰的姿态习惯提醒。
当前不足主要不是阈值不够灵敏，而是部分观察量不能唯一对应所声称的姿态：
肩宽投影缩小不一定是肩膀前扣，脸变大不一定是躯干前倾，嘴唇分开不等于口呼吸。
建议先修正可判定范围与缺失状态，再优化时序和阈值，最后用标注集校验。

## 当前嘴部方案

已用真机证实，仅 JAW_OPEN 会漏掉下颌不动的轻微分唇。因此结合上下唇语义网格和个人闭嘴基线，
并使嘴部卡片与综合评分同帧更新。完整阈值、回放数据和限制见 [Preview023.md](Preview023.md)。
阈值是开发初值，不是从大规模训练/验证集推得；不把嘴部状态声称为呼吸方式。

仍需验证或改进：

- 嘴唇校准时稳定张嘴也可能被接受，需用明确的闭嘴动作提示和可靠的绝对闭合特征检查；不能凭本次单人的绝对唇距设全人群硬上限。
- 同帧快速响应与噪声误报冲突，可在更高频的低成本嘴部采样上做短窗一致性；不能靠延长到十几秒才反映嘴部卡片。
- 目前按嘴宽归一化，用网格 X 轴选中部，已测缩放和平移，不宣称任意旋转不变。需验证侧脸、微笑、遮挡与不同唇形。
- 原生跟踪可能比旧 JPEG 抽帧更耗电，需测 30/60 分钟温升、耗电与帧时延，再决定采样/休眠策略。

## 建议实施顺序

1. 先统一 UNKNOWN、评分有效性和统计覆盖率，避免“没看见”被当作“很好”。
2. 拆分方向、保留全部活跃事件、添加人脸/骨架关联；每项都以固定反例加回归测试。
3. 引入稳定性校准、相机位置变化检测和会话数据版本，再处理伸手与含胸的时序区分。
4. 建立经过同意的真人标注集：闭嘴/分唇/说话、伸手打字、躯干转动、前倾、低头/仰头、丢脸与多人物。
   按用户和设备分离验证集，分别报告检出率、误报次数/小时、响应延迟和有效检测覆盖率。

不建议现在全面重写或盲目把阈值调低。先修复能用代码证实的逻辑缺陷，再判断是否需要时序模型。
