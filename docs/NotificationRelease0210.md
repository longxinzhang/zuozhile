## 日常启用与使用

1. 进入「设置 → 腕上提醒」。新安装默认普通通知同步，开关仍默认关闭；已有显式A/B路线与启用状态保持原样。若之前选了Wear Engine，可停止守护后手动切回普通通知。
2. 开启腕上提醒，点击手机通知准备按钮。准备只检查/申请权限并核实服务提醒渠道，不发送测试；已准备过的设置在重启后静默复查。
3. 在华为运动健康中允许坐直了消息通知，并开启多设备提醒或手机亮屏时提醒。同步目标与腕上振动由运动健康和穿戴设备设置决定。
4. 回到守护页开始真实守护，无需每次先点测试。只有前台真实检测经原调度器确认三级、且新有效样本当前仍低于50分，才发送一条带当前分数和可靠建议的普通通知。
5. 连续低分最短10秒一次，到期仍等新的有效样本；2/3/5秒采样保持原样，不是后台定时群发。停止、后台、校准、无效数据或恢复时不会补发。

普通通知是正式主入口；未获审批的Wear Engine仍可在折叠高级通道中显式选择，未配置时提示待配置，不自动回退。发送失败或超时不重试、不并发补偿。开关不会由升级自动开启。

## 测试、记录与故障处理

- 「腕上提醒 → 测试与记录」保留单条测试、最近结果、手动确认与最近诊断。测试不启动相机、不写坐姿统计，与正式提醒和另一通道共享10秒冷却。
- 请求结果、测试/正式来源、提交状态、错误与用户确认关联到独立事件；最多100条、24小时，仅保存本机。界面展示最近5条，重开应用仍可回看。清除记录不重置冷却。
- 旧版最后一次测试迁移为一条历史确认；不伪造被覆盖的旧记录，不改变其原路线或用户选择。
- 权限/渠道检查或冷却保存失败时，本次测试显示“未提交”并取消沿用上次成功的确认；未提交测试不能确认已收到。准备操作仍不消费发送冷却。
- 权限失败后需显式检查或准备；退后台再回来会保留正确的待配置/失败原因，不显示过时的“已离开前台”，也不因恢复前台自动发送。
- 历史「手机通知同步测试」迁入「设置 → 开发者工具」，其独立ID `29001`、60秒冷却和10秒发送延迟保持原样，不与正式ID `29002`混淆。

评分、阈值、校准、灵敏度、手机光效和双短振保持原逻辑；手机双短振仍独立60秒冷却。正式通知仍请求关闭额外手机声音与振动，固定ID更新一条，手机60秒自动清除；手环副本的清除由设备决定。
