1. 开发者在 AGC 为包名 `com.longxin.zuozhile` 对应应用申请 Wear Engine“设备基础信息 + 消息通知”，个人开发者可申请；这是官方服务准入，不是手机 runtime 健康权限，不申请心率、传感器、佩戴状态或设备序列号权限。
