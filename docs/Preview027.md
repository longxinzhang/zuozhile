# 0.2.7 骨骼监看开发预览

初版日期：2026-09-23；真机续测：2026-09-29。版本 0.2.7 / versionCode 1000008。

## 已实现

- 入口：设置 → 开发者工具 → 骨骼监看。默认关闭，相机画面需单独开启。提供镜像开关、采集一帧、帧龄、可靠点数、图像尺寸及多人提示。
- 读取 Core Vision 原始 17 点，沿用检测器原有主骨架选择结果。只画置信度至少 0.35、坐标有效且在输入图像内的关节；只连接两端均可靠的骨段。此阈值仅影响可视化，不影响评分或校准。
- 坐标使用检测输入图像的真实宽高，而不是手机屏幕或相机预览 surface 的尺寸。图像和骨骼共享居中 contain 变换与镜像，既不裁掉人体，也不拉伸体型。
- 可选图像是同一份旋转后的检测 PixelMap 的内存 JPEG，不读取另一条相机预览。原 PixelMap 在编码结束后仍由原检测源正常释放。图像和关键点以单个帧对象传递，新图像就绪前不画新骨骼。
- 调试视图只保留当前帧，不存储图片、视频、关键点历史或云端数据。关闭、切页、收起或退后台清除视图状态，取消订阅和计时器；会话编号阻止晚到帧恢复画面。
- 守护期间订阅既有检测结果，频率仍为用户设置的 2/3/5 秒。超过两倍采样间隔加一秒、且至少六秒未更新时清除守护旧帧。非守护期间保留明确标注时间的单帧供检查。
- 新“采集一帧”复用原相机源及操作锁，但不调用评分、提醒、统计或校准保存。已经守护或其他高影响操作进行中不可再启动单帧；单帧结束或失败后释放相机源。后台不启动新的单帧请求，已在途请求结束后由 finally 释放。
- 模拟源不生成伪造的“真实骨骼”，入口明确不可用。多人时只显示原算法选中的骨架，不新增或改动人脸与人体的匹配规则。

## 代码边界

新增 SkeletonGeometry、SkeletonDebugFeed、SkeletonDebugPanel。CoreVisionPostureDetector 仅增加只读调试观察点；返回的 PostureSample、检测输入、主骨架/人脸选择和模型调用次数不变。

CoreVisionPostureSource、C++ AR 模块、PostureEvaluator、PostureCalibration、ReminderEngine、会话存储均未修改。首页和原有守护功能没有新增常驻画面或后台相机。

9 月 29 日经用户明确同意，ARPostureSource 仅补充 `srcPixelFormat: image.PixelMapFormat.RGBA_8888`。原生缓冲区为 RGBA，而 ImageKit 未指定源格式时默认按 BGRA 读取；此前的 `pixelFormat` 只声明目标格式。此修复改变送入 Core Vision 的颜色，不能声称检测输入字节完全不变，但不修改评分、阈值、校准或提醒规则。测试精确允许这一行差异，其他源代码保护仍保留。

开启相机叠加会增加 JPEG 编码和 UI 渲染开销，这不是零成本功能；关闭监看不编码、不绘制、不增加检测次数。实际耗时、功耗及长时间内存表现仍需真机测量。
